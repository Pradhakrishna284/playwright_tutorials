KEY CONCEPTS EXPLAINED

THE MOST CRITICAL CONCEPT - inputValue() vs textContent()
──────────────────────────────────────────────────────────

WHY THIS MATTERS:
  This is the #1 cause of test failures and silent bugs!

QUICK DECISION:
  Is it a FORM INPUT?
    (<input>, <textarea>, <select>)
    └─ YES → Use inputValue() ✓
    └─ NO  → Use textContent() ✓

EXAMPLES:

  Form Input (use inputValue):
    HTML: <input id="name" value="John">
    ✓ const val = await nameInput.inputValue();  // "John"
    ✗ const txt = await nameInput.textContent();  // ""

  Button (use textContent):
    HTML: <button>Click Me</button>
    ✓ const txt = await button.textContent();   // "Click Me"
    ✗ const val = await button.inputValue();    // null

  Dropdown (for value use inputValue, for label use textContent):
    HTML: <select><option value="us">United States</option></select>
    ✓ const val = await select.inputValue();    // "us"
    ✓ const label = await select.locator('option:checked').textContent(); // "United States"
    ✗ const txt = await select.textContent();   // All options text

COMPLETE REFERENCE TABLE:
  Element              | To Get              | Use This           | Result
  ────────────────────────────────────────────────────────────────────────────
  <input type="text">  | Entered text        | inputValue()       | "text" ✓
  <textarea>           | Text content        | inputValue()       | "text" ✓
  <select>             | Selected value      | inputValue()       | "value" ✓
  <button>             | Button label        | textContent()      | "Click" ✓
  <a href="...">       | Link text           | textContent()      | "Link" ✓
  <div>Text</div>      | Div content         | textContent()      | "Text" ✓


PLAYWRIGHT ACTIONS - COMPLETE REFERENCE
─────────────────────────────────────────

TEXT INPUT METHODS:
  fill(text)                      Fast, clears field, recommended (90% usage)
  pressSequentially(text)         Slow, char-by-char, tests handlers
  type(text)                      Alternative typing method

INTERACTION METHODS:
  click()                         Single left click
  dblclick()                      Double click
  click({button: 'right'})        Right-click
  check()                         Select checkbox/radio
  uncheck()                       Deselect checkbox
  selectOption(value)             Select dropdown option

KEYBOARD METHODS:
  press(key)                      Press keyboard key
  pressSequentially(text)         Type with character events

FOCUS/HOVER METHODS:
  focus()                         Set focus to element
  blur()                          Remove focus
  hover()                         Move mouse over element

SCROLL METHODS:
  scrollIntoViewIfNeeded()        Auto scroll into view if needed
  page.evaluate()                 Custom JavaScript scroll
  page.mouse.wheel()              Mouse wheel scroll

FILE/DRAG METHODS:
  setInputFiles(path)             Upload file(s)
  dragTo(target)                  Drag to target element

VALUE RETRIEVAL METHODS:
  inputValue()                    Get form input value
  textContent()                   Get element text content
  getAttribute(name)              Get HTML attribute value

ASSERTION METHODS:
  toBeVisible()                   Assert element visible
  toBeEnabled()                   Assert element enabled
  toBeChecked()                   Assert checkbox checked
  toHaveValue(value)              Assert input has value

================================================================================
COMMON TROUBLESHOOTING
================================================================================

Problem: Test fails with "Cannot read property 'inputValue' of null"
─────────────────────────────────────────────────────────────────────
Cause: Element not found by locator
Fix:   1. Check locator is correct (ID, class, selector)
       2. Use page.locator() correctly
       3. Wait for element with waitForSelector()

Problem: "Expected empty string but got expected value"
────────────────────────────────────────────────────────
Cause: Using textContent() instead of inputValue() on form input
Fix:   Read TEST 8 carefully
       Change: await field.textContent() → await field.inputValue()

Problem: "Expected null but got expected value"
────────────────────────────────────────────────
Cause: Using inputValue() on non-form element like button
Fix:   Change: await button.inputValue() → await button.textContent()

Problem: fill() doesn't work on password field
──────────────────────────────────────────────
Cause: fill() works fine, issue is elsewhere
Fix:   Check field is visible: await expect(field).toBeVisible()
       Check field is enabled: await expect(field).toBeEnabled()

Problem: Click fails with "Element is covered by another"
──────────────────────────────────────────────────────────
Cause: Element overlapped by another (modal, overlay, etc.)
Fix:   1. Wait for overlay to disappear
       2. Use force: true as last resort
       3. Scroll element into view first

Problem: Dropdown selectOption() doesn't work
──────────────────────────────────────────────
Cause: Wrong value or element not found
Fix:   1. Verify value attribute: await select.getAttribute('value')
       2. Check locator finds select: console.log() debug
       3. Use selectOption({label: 'Text'}) if value unknown

Problem: pressSequentially() times out
───────────────────────────────────────
Cause: Delay too long or field validates on every keystroke
Fix:   1. Reduce delay: {delay: 50}
       2. Fill instead if not testing handler
       3. Increase timeout: {timeout: 10000}

Problem: Test passes locally but fails in CI
──────────────────────────────────────────────
Cause: Timing/network issues in CI environment
Fix:   1. Add explicit waits: await page.waitForSelector()
       2. Check actionability: await expect().toBeVisible()
       3. Increase timeout for CI: timeout: 30000
