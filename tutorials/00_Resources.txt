================================================================================
                            QUICK REFERENCE
================================================================================

Most Common Locator Methods:
- page.getByRole()        → Recommended for accessibility
- page.getByText()        → Find by visible text
- page.getByLabel()       → Find form inputs by label
- page.getByPlaceholder() → Find by placeholder attribute
- page.getByAltText()     → Find images by alt text
- page.getByTitle()       → Find by title attribute
- page.getByTestId()      → Find by test-id attribute
- page.locator()          → CSS/XPath selectors (fallback)

Chaining & Filtering:
- locator.filter()        → Filter by text or other locators
- locator.first()         → Get first matching element
- locator.last()          → Get last matching element
- locator.nth()           → Get nth matching element
- locator.and()           → Combine multiple conditions
- locator.or()            → Match any of the conditions

================================================================================
                            NOTES & TIPS
================================================================================

✅ DO:
- Prefer user-facing attributes (role, text, label)
- Use getByRole() whenever possible for accessibility
- Chain locators for precise targeting
- Keep locators simple and maintainable
- Use data-testid for dynamic content when needed

❌ DON'T:
- Avoid fragile CSS selectors based on structure
- Don't rely on XPath unless absolutely necessary
- Avoid using text selectors for frequently changing content
- Don't use generated class names or IDs
- Avoid overly complex locator chains

💡 Pro Tips:
- Use Playwright Inspector to debug locators (npx playwright codegen)
- Enable strict mode to catch ambiguous locators
- Write locators that work across different viewports
- Test locators in multiple browsers
- Document complex locator strategies in your code
