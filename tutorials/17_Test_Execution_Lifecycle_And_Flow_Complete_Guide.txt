================================================================================
STAGE 1: COMMAND EXECUTION & NPX RESOLUTION (0-500ms)
================================================================================

WHAT HAPPENS:
┌────────────────────────────────────────────────────────────────────────────┐
│ User Types: npx playwright test pw_xpath.spec.ts                          │
└────────────────────────────────────────────────────────────────────────────┘

NPX processes the command:
1. Check if 'playwright' is installed locally in node_modules
2. If not found, check npm registry (rare, already installed)
3. Locate: node_modules/.bin/playwright
4. Load the Playwright CLI executable

Playwright CLI starts:
1. Spawn Node.js process
2. Load Playwright test runner code
3. Parse command-line arguments:
   ├─ Command: test
   ├─ File pattern: pw_xpath.spec.ts
   ├─ Other flags: (none in this case)
   └─ Default values: workers, timeout, retries, etc.

TIMELINE:

t=200ms  Node.js process spawned
t=300ms  CLI executable loaded
t=500ms  Arguments parsed, ready for next stage

PROCESS HIERARCHY:

    Main Process (CLI)
    ├─ Reads config
    ├─ Discovers tests

    ├─ Main sends test to Worker

    └─ Continuous throughout execution

    Main Process                          Worker Process
    ─────────────────────────────────────────────────────
    1. Spawns worker                      Worker starts

    5. Sends Test 7                   →   Worker runs Test 7
    6. Waits for result               ←   Worker sends result
    7. Cleanup signal                 →   Worker cleans up

KEY TAKEAWAYS
================================================================================

1. Command triggers NPX which spawns Playwright CLI
   → All happens automatically, transparently

2. Configuration loads and auto-detects CPU cores
