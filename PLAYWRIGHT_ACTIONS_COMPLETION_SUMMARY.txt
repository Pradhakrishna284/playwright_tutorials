MOST CRITICAL LEARNING POINTS
═══════════════════════════════════════════════════════════════════════════════

1. THE GOLDEN RULE (Prevents 30% of test failures):
   ┌─────────────────────────────────────────────────────────────────────────┐
   │  Is it a FORM INPUT? (<input>, <textarea>, <select>)                     │
   │    └─ YES  → Use inputValue()                                            │
   │    └─ NO   → Use textContent()                                           │
   │                                                                           │
   │  Using the wrong method = Silent test failures!                         │
   └─────────────────────────────────────────────────────────────────────────┘

2. FILL() DOMINATES (Use 90% of the time):
   ✓ fill() - Clear field and type text (RECOMMENDED)
   ✗ pressSequentially() - Only when testing input handlers/autocomplete

3. EACH METHOD HAS ONE PURPOSE:
   • fill()              → Text input ONLY
   • click()             → Interactions ONLY
   • check()/uncheck()   → Checkboxes/radios ONLY
   • selectOption()      → Dropdowns ONLY
   • inputValue()        → Form inputs ONLY
   • textContent()       → ANY element's text
   • getAttribute()      → HTML attributes

4. ACTIONABILITY IS AUTOMATIC:
   • click(), fill(), check() automatically handle:
     - Visibility checks
     - Enabled checks
     - Scrolling into view
     - Waiting for readiness

5. MASTER TEST 8:
   • inputValue() vs textContent() comparison
   • Shows exactly what each method returns
   • Covers all element types
   • Demonstrates right vs wrong usage
   • Critical for preventing test failures
